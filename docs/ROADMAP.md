# Roadmap

Missingmoji is currently in the planning stage. This roadmap describes the intended direction and may change as the project develops.

## Planning

- [x] Create project repository
- [x] Define initial project direction
- [x] Expand the concept into a customizable Android keyboard
- [ ] Finalize name, branding, and visual style
- [ ] Define the first-release feature scope
- [ ] Design the keyboard, toolbar, and customization screens
- [ ] Define supported Android versions and devices
- [ ] Decide how custom image/sticker insertion and fallbacks should work

## Initial development

- [ ] Set up the Android project with Kotlin and Jetpack Compose
- [ ] Implement an Android Input Method Service
- [ ] Build the core keyboard layout and key input
- [ ] Add keyboard height, key size, and spacing controls
- [ ] Add theme and appearance customization
- [ ] Build configurable toolbar and keyboard settings
- [ ] Add language/layout selection
- [ ] Add emoji and sticker browsing
- [ ] Create the custom artwork asset pipeline
- [ ] Add initial seahorse and robber artwork
- [ ] Implement favorites, recents, and search
- [ ] Add optional sound and haptic settings

## Testing and refinement

- [ ] Test text input and image/sticker insertion across Android apps
- [ ] Check behavior with different screen sizes and Android versions
- [ ] Review accessibility, usability, and one-handed use
- [ ] Review privacy and minimize unnecessary data collection
- [ ] Improve performance and battery usage

## Release

- [ ] Prepare documentation and screenshots
- [ ] Publish the first public release

Items are tentative. The first release will focus on a reliable keyboard and a useful set of customization options before expanding into more advanced features.
